# ai_website

This is my personal website generated by AI tools.

## Resume chatbot with OpenAI

The chatbot now uses:

- front-end knowledge files from `src/data/resumeKnowledge.json` and `src/data/personalKnowledge.json`
- a local proxy server in `server/index.mjs`
- a Vercel serverless route in `api/chat.mjs`
- OpenAI Responses API with a reasoning model
- OpenAI embeddings for semantic retrieval

## Local setup

1. Copy `.env.example` to `.env`
2. Set `OPENAI_API_KEY`
3. Run `npm run dev`

This starts:

- Vite on `http://localhost:5173`
- the local OpenAI proxy on `http://localhost:8787`

## Structure notes

- `src/data/resumeKnowledge.json` stores professional RAG knowledge.
- `src/data/personalKnowledge.json` stores life and personal-context knowledge.
- `src/components/ResumeChatbot.jsx` is the floating chatbot UI used across the site.
- `api/chat.mjs` is the Vercel-compatible serverless API entrypoint.
- `server/services/chatService.mjs` is the main agent-like orchestration layer.
- `server/services/intentClassifier.mjs` uses the model to classify whether a question is `resume`, `personal`, or `general`.
- `server/knowledge/retrieval.mjs` uses embeddings plus light keyword scoring to retrieve the most relevant knowledge chunks before response generation.

## Request flow

1. A user opens the site and submits a message through `src/components/ResumeChatbot.jsx`.
2. The frontend sends the question to `POST /api/chat`.
3. `server/routes/chatRoute.mjs` validates the request and forwards it to the chat service.
4. `server/services/intentClassifier.mjs` asks the model to classify the question as `resume`, `personal`, or `general`.
5. `server/knowledge/retrieval.mjs` chooses the right knowledge source and retrieves the most relevant chunks using embeddings-based semantic search.
6. `server/prompts/chatPrompt.mjs` builds the grounded prompt using the selected context.
7. `server/services/chatService.mjs` sends the final request to the OpenAI Responses API.
8. The response is returned to the frontend and rendered in the floating chatbot UI.

## Vercel deployment

For Vercel, the chatbot API is served from:

- `api/chat.mjs`

Set these environment variables in your Vercel project settings:

- `OPENAI_API_KEY`
- `OPENAI_MODEL`
- `OPENAI_REASONING_EFFORT`
- `OPENAI_INTENT_MODEL`
- `OPENAI_EMBEDDING_MODEL`

Notes:

- Do not commit your real `.env` file.
- Vercel reads environment variables from its dashboard, not from your local `.env`.
- Local development still uses `server/index.mjs` plus the Vite proxy.
